# A/B Testing

## Problema que aborda

Se necesita comparar el impacto de variantes para grupos de usuarios según una hipótesis de producto.

## En qué consiste

Asigna grupos de forma consistente a versiones distintas y compara métricas de experiencia o negocio durante un periodo definido.

## Características y compromisos

Permite evaluación experimental. Necesita diseño estadístico, segmentación, consentimiento y evitar confundir cambios simultáneos.

## Cuándo considerarlo

Validar hipótesis de producto. No equivale a canary: el objetivo principal es comparar resultados de usuario, no solo detectar fallas técnicas.
