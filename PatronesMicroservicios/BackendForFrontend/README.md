# Backend for Frontend (BFF)

## Problema que aborda

Una API general obliga a clientes distintos (web, móvil, dispositivo) a recibir datos excesivos o hacer muchas llamadas.

## En qué consiste

Crea una capa de backend adaptada a una experiencia o tipo de cliente. Compone o transforma datos para satisfacer sus necesidades.

## Características y compromisos

Reduce complejidad y sobrecarga de cada interfaz. Puede duplicar lógica, por lo que conviene compartir capacidades de dominio fuera de los BFF.

## Cuándo considerarlo

Cuando varios clientes tienen necesidades de interacción claramente distintas y esa adaptación no pertenece al dominio.
