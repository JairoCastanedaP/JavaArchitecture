# Modelo-vista-controlador

## Problema que aborda

La interfaz, los datos y el tratamiento de acciones están acoplados, lo que dificulta cambiar o probarlos.

## En qué consiste

Divide la interfaz en Modelo (datos y reglas), Vista (presentación) y Controlador (interpreta acciones y coordina). Los marcos pueden variar el flujo exacto de interacción.

## Características y compromisos

Separa preocupaciones y admite distintas vistas sobre datos. Puede añadir indirección y no siempre encaja con interfaces pequeñas o reactivas.

## Cuándo considerarlo

Aplicaciones con interfaces que manejan múltiples interacciones y necesitan separar presentación de reglas.
