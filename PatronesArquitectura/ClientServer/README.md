# Cliente-servidor

## Problema que aborda

Varios consumidores necesitan solicitar capacidades y datos de un proveedor compartido.

## En qué consiste

Separa consumidores (clientes) de proveedores (servidores) que exponen operaciones mediante un protocolo. El cliente inicia solicitudes y el servidor responde.

## Características y compromisos

Centraliza datos y servicios, y permite atender distintos tipos de cliente. Introduce dependencia de red, disponibilidad del servidor y consideraciones de seguridad y capacidad.

## Cuándo considerarlo

Aplicaciones web, servicios de datos y sistemas con responsabilidades de solicitud y respuesta bien delimitadas.
