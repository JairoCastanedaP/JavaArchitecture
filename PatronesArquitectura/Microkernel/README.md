# Microkernel (núcleo mínimo)

## Problema que aborda

Un producto necesita un conjunto estable de funciones básicas y capacidades opcionales que varían entre instalaciones.

## En qué consiste

Mantiene un núcleo con servicios esenciales y conecta complementos o módulos mediante contratos estables. El núcleo coordina la extensión sin depender de cada complemento concreto.

## Características y compromisos

Permite ampliar o personalizar el producto. La compatibilidad de complementos, el aislamiento, el ciclo de vida y la seguridad requieren diseño cuidadoso.

## Cuándo considerarlo

Plataformas extensibles, herramientas, productos con ediciones configurables y sistemas de complementos.
