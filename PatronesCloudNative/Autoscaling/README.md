# Escalado automático

## Problema que aborda

La demanda cambia, y una capacidad fija puede desperdiciar recursos o quedar corta.

## En qué consiste

Ajusta el número o tamaño de instancias según métricas, políticas y límites definidos. Puede escalar horizontal o verticalmente.

## Características y compromisos

Alinea capacidad con demanda. La métrica, los tiempos de arranque, el límite máximo y los costos deben controlarse; no arregla cuellos de botella de diseño.

## Cuándo considerarlo

Cargas variables y suficientemente independientes. Combínalo con métricas útiles, límites de costos y pruebas de carga.
