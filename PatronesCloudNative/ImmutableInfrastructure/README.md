# Infraestructura inmutable

## Problema que aborda

Modificar servidores en producción de forma manual genera diferencias difíciles de reproducir.

## En qué consiste

Reemplaza instancias por unidades nuevas construidas desde una definición versionada, en vez de parchear servidores en sitio.

## Características y compromisos

Mejora repetibilidad y auditoría, y simplifica volver a una versión anterior. Exige automatización, gestión de estado y estrategia de datos persistentes.

## Cuándo considerarlo

Infraestructura automatizada donde las instancias pueden reconstruirse y los datos viven fuera de ellas.
