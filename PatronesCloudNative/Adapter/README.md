# Adaptador cloud native

## Problema que aborda

Una aplicación o componente expone métricas, protocolos o formatos que la plataforma de operación no entiende directamente.

## En qué consiste

Un componente adaptador traduce la interfaz o formato existente a uno esperado por otros componentes, como convertir métricas a un formato de monitorización.

## Características y compromisos

Permite integrar componentes legados sin modificarlos. Deben controlarse pérdida de información y mantenimiento del traductor.

## Cuándo considerarlo

Integración entre sistemas con contratos incompatibles; es una especialización contextual del patrón Adapter estructural.
