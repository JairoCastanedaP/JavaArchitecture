# Ambassador

## Problema que aborda

La aplicación necesita comunicarse con servicios externos o remotos y se quiere ocultar complejidad de red.

## En qué consiste

Un proxy acompañante realiza solicitudes de red en nombre de la aplicación y puede gestionar conexiones, descubrimiento o políticas.

## Características y compromisos

Aísla detalles de conexión del código cliente. El proxy añade saltos, operación y posibles puntos de falla.

## Cuándo considerarlo

Integración uniforme con servicios externos o redes complejas; distinguirlo de API Gateway, que suele recibir tráfico de entrada.
