# Patrones de diseño en Java

Este espacio contiene ejemplos independientes de los patrones GoF, con código comentado y documentación en español.

- [Patrones creacionales](PatronesCreacionales/README.md): 5 patrones para organizar la creación de objetos.
- [Patrones estructurales](PatronesEstructurales/README.md): 7 patrones para componer clases y objetos.
- [Patrones comportamentales](PatronesComportamentales/README.md): 11 patrones para organizar la colaboración entre objetos.

Cada carpeta de patrón incluye un README con su propósito, estructura, características, recomendaciones de uso y comandos para compilar y ejecutar el ejemplo.

Las categorías descriptivas de arquitectura y sistemas distribuidos se encuentran junto a esta carpeta:

- [Patrones de arquitectura](../PatronesArquitectura/README.md)
- [Patrones de microservicios](../PatronesMicroservicios/README.md)
- [Patrones Cloud Native](../PatronesCloudNative/README.md)
- [Patrones de despliegue](../PatronesDespliegue/README.md)
